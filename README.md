# PowerBill Pro

Electricity Billing Desktop Application developed using Java.

## Technologies Used
- Java 21
- Java Swing
- Apache Maven
- VS Code

## Features
- Consumer Registration
- Consumer Search
- Electricity Bill Generation
- Printable Bill Receipts
- Payment Management
- Billing History
- Monthly Reports
- Report Export

## Storage
Local text files.

## Run the Application
Compile using Maven:

mvn clean compile

Launch:

java -cp target/classes com.example.App

## Tariff
Uses sample progressive electricity tariff rates.
